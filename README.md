## Actual recordings

`assets/media-manifest.json` connects supplied, redacted recordings to the portfolio.
Null entries retain the current screenshots and do not display an empty video player.

- `agent`: actual Agent recording, shared by the execution stage and Automation in Practice.
- `product-flow`: planning/User Flow recording in the product case.
- `product-prototype`: actual frontend prototype recording; shown only when a recording is supplied.

Each entry can contain `src`, `poster`, `title` and optional Korean `captions` (VTT).
Use local `assets/` MP4/WebM paths. Videos use native controls, inline mobile playback,
no autoplay, and no initial video download. Redact client names in the supplied recording
before connecting it; presentation overlays are not a privacy measure.
